\chapter{Emotion Detection Prototype}
\label{appendix:emotion-detection}

This appendix documents the batch emotion-detection experiment requested for the OpenAI vision-capable models. The script scans a folder of test images, loads the API key from the environment (including optional \texttt{.env} files) or an interactive prompt, queries the Responses API once per image, and prints both a concise summary and the raw JSON payload for auditing.
